## What I'm Working On

### PetPulse: Smart Pet Activity Monitor
A wearable system built on the Seeed Studio XIAO nRF52840 Sense that classifies pet activity as still, walking, or running. The firmware extracts statistical motion features from the accelerometer and gyroscope and sends results over Bluetooth Low Energy to a native iOS app that I'm building in SwiftUI and CoreBluetooth. The long-term goal is flagging unusual changes in a pet's activity patterns.

**Stack:** `C++` · `Arduino` · `Swift` · `SwiftUI` · `CoreBluetooth` · `BLE`
